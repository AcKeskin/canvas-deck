Delta-only spec from cycle run 2026-10-25-run1, slice A1. No interview: the confirmed slice settles the approach.

## Problem
The key handler in `src/present/Presenter.tsx` takes ↓ PageDown Enter for next, ↑ PageUp Backspace for back, and H for help. The `HELP` table shows only "→ Space", "←" and "?". The README "Present mode keys" table already lists the full set.

## Goals
- Make the `HELP` rows match the key handler and the README table.

## Non-goals
- Building the overlay and the handler from one shared key map (reveal.js style). Possible follow-up.
- Changing any key binding, the overlay look, or the README.
