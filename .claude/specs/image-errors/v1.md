# Spec - image-errors (v1)

Delta-only spec from cycle run 2026-10-25-run2, slice A7. No interview: the confirmed slice settles the approach.

## Problem
Vision v1, cross-cutting concerns: "never lose user content; failed saves or loads show an Obsidian notice and keep the in-memory state". Three paths break this:
- `CanvasEngine.saveFile` (`src/canvas/engine.ts:111`): `store.save` can reject (`vault.createBinary` on a read-only or synced folder, a name clash). `handleChange` calls it with `void`, so the rejection is dropped. The image has no entry in `slide.images` and is gone after a reload. The user sees nothing. Each later scene change tries the save again.
- `src/main.ts:45` "Insert vault image" and `src/deck/deck-view.tsx:136` file drop call `void engine.insertImage(...)`. `insertImage` throws on an unreadable file or a broken image. The rejection is dropped; nothing happens on screen.

## Goals
- The user learns about a failed pasted-image save from an Obsidian notice, once per image.
- The user learns about a failed vault-image insert from an Obsidian notice.
- The engine stays Obsidian-free.

## Approach
- `vaultImageStore.save` (`src/obsidian/vault-image-store.ts`) shows the notice and rethrows. It is the Obsidian side of the save, so the engine needs no new callback.
- `CanvasEngine.saveFile` catches the rejection, logs it with `console.error`, and remembers the file id so it does not try again. One notice per image follows from one save call per image.
- The two `insertImage` callers add `.catch` with a notice naming the file.

## Rejected approaches
- An `onError` callback from the engine through `SlideCanvas`, `DeckEditor` and `Presenter` props to `DeckView`. Same result, four more files and two more props.
- Retrying a failed save on every change with a deduped notice. A failure from a read-only folder or a name clash does not fix itself between keystrokes; the user can delete and paste again.

## Non-goals
- Saving the image somewhere else when the vault write fails.
- Notices for `loadImages`: it skips missing files on purpose.
- Errors in PDF or HTML export.
