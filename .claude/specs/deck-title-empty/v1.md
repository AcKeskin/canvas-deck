# Spec - deck-title-empty (v1)

Delta-only spec from cycle run 2026-10-25-run3, slice A8. No interview: the confirmed slice settles the approach.

## Problem
`serializeDeck` writes `## ` for an empty title. `splitHeader` (`src/deck/deck-format.ts`) trims the chunk first, so the line becomes `##` and fails `startsWith("## ")`. The title stays empty and "##" lands in the notes. The next save grows it. This breaks the deck-store done-criterion of a round trip with identical output.

## Goals
- Read a bare `##` line as an empty title.

## Non-goals
- Changing what `serializeDeck` writes.
- Keeping a title of only spaces (it trims to empty, which is fine).
