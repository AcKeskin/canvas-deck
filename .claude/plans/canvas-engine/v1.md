## Context
canvas-engine is the per-slide infinite canvas for the canvas-deck Obsidian plugin. Built on Excalidraw (MIT). Each slide has a 16:9 start frame, ordered saved views, sketch or clean style per object, vault images linked by path, and a camera API that slide-navigator and presenter call. Target ~2,000 objects per slide. Mobile is checked with Obsidian's mobile emulation; the user has no iPad.

No repo exists yet. Paths below are relative to a new plugin repo laid out like obsidian-sample-plugin. Repo location is picked at execute time.

## Done-criteria (from spec)
1. `npm run build` and `npm test` pass; tests round-trip a slide (frame, saved views, objects) through save/load with identical output
2. A test slide with 2,000 mixed objects pans and zooms at 50+ fps on desktop Obsidian, and 30+ fps with mobile emulation on (app.emulateMobile(true))
3. Going to a saved view animates the camera to exactly that view's bounds, and going home returns to the 16:9 frame
4. Pen strokes vary width with pointer pressure (tested with synthetic pointer events carrying pressure), and a vault image dropped on the canvas still renders after restarting Obsidian
